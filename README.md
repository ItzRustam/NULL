# NULL
Multi Agent System to Automate Systems.

## Roles & Agents
### Head Agent
**NULL** : Main Head Agent which will give task to other Agents.

### Sub-Agents
**Alex**: The Researcher which can access web, Wikipedia & Arxiv.
**CoreX** The Programmer which can write code & Access web for latest Information.
**Cod**: The File Manager which can have permissions to write & read files and run python code.
**Techno**: The RSRoute Helper Integrated into NULL can call RSRoute Server for automate testing and working.

### Security Manager
**John**: The Security Guard to save from malicious code.
